# 论文创新增强计划

## 研究定位

将任务表述为一般智能垃圾对象分类，不强制限定医疗废物。现有 4×4 模拟
传感器清单在本阶段按已观测传感器使用，接口保持不变，以便后续直接替换为
同 schema 的真实记录。

## 核心方法

实现“跨模态一致性感知的传感器可靠性融合”：

1. 训练时以纯软件方式随机模拟传感器缺失、噪声、偏移和卡死。
2. 根据视觉特征与全部候选类别语义上下文预测传感器潜表示及不确定性。
3. 根据实测/预测潜表示的差异、余弦一致性、不确定性和可用性估计可靠度。
4. 可靠度高时主要采用输入传感器，可靠度低或缺失时退化到预测潜表示。
5. 保留原 CE + Focal，并增加异方差潜特征重建和可靠度校准损失。

## 验收标准

- 不添加硬件、外部数据或在线 API 依赖。
- 默认正常传感器输入和原调用方式保持兼容。
- 缺失传感器可以在 CLI 和模型接口中显式表达并完成前向。
- 退化器输出保持有限值和合法范围，固定随机种子可复现。
- 模型输出可靠度、潜特征预测、不确定性和一致性，形状及范围明确。
- 联合损失可反向传播；训练历史可分别观察重建与校准损失。
- 配置可关闭各项退化和辅助损失，便于论文消融实验。
- 全量回归测试、数据校验及原系统隔离检查通过。

## 审查拓扑

- 协调者：范围、证据与最终决策。
- 开发者：模型、训练、CLI、配置、测试和说明。
- 独立功能审查者：运行测试并检查缺失/污染传感器状态和兼容性。
- 无用户界面，因此不设置视觉审查。

回合预算 2–3 轮；总分达到 4.3/5 且无关键问题时停止。
