# 多模态医疗废品分类：交付计划

## 交付类型

隔离式 Python 算法子项目（数据构建、模拟传感器、多模态融合分类、训练/推理与测试）。

## 范围与约束

- 所有新增代码、清单、模拟传感器数据、测试和说明均位于 `smartBin/multimodal-fusion-classifier/`。
- 不修改、移动或复制 `smartBin/data/` 中的原始图像；训练清单仅保存原图路径和目标框，运行时在内存中裁剪。
- 不修改现有 `ultralytics/`、`myprogram/`、`device-simulator/` 或根级配置/权重。
- 默认离线规则模拟必须可用；Qwen3-VL-Flash 是可选的图像参考增强器，缺少 API Key 时自动回退且不阻断构建。
- 文本、JSON、JSONL、YAML 与 Python 源码统一使用 UTF-8。

## 专利到实现的映射

- 视觉分支：本地 `../yolo11s-seg.pt` 的 YOLO11s-seg 主干，多尺度特征池化，冻结前 5 层。
- 文本分支：CLIP ViT-B/16，512 维文本特征，冻结前 3 层 Transformer。
- 传感器分支：4x4 阵列上采样到 16x16、逐样本归一化、1x1 卷积映射到 512 维。
- 融合分支：三路 Adapter、LeakyReLU、Dropout(0.3)、FiLM、余弦注意力、512→128 下投影、8 头双向模态注意力、128→512 上投影、残差、多尺度动态加权（初值 0.3/0.5/0.2）。
- 训练：Cross Entropy + Focal Loss，AdamW、余弦退火、5 epoch warmup；默认专利参数为 batch 16、lr 1e-4、weight decay 1e-5、100 epochs。

## 验收标准

1. 能从现有 LabelMe JSON 多边形标注构建 train/val/test JSONL（同时允许兼容 VOC），按原始图像分组切分且无跨集合泄漏。
2. 生成与每个分类样本绑定的、可复现且范围合法的 4x4 模拟传感器记录。
3. 可选 Qwen3-VL-Flash 生成器使用原图目标框内存裁剪、Base64 图像输入和 JSON 结构化输出，支持重试、断点续建、校验与规则回退。
4. 模型前向输出 `[batch, num_classes]`，融合权重可观测，联合损失可反向传播。
5. 提供构建、校验、训练、预测命令及中文 README；默认路径不依赖调用者当前工作目录。
6. 自动测试覆盖数据解析/切分、模拟器确定性、Qwen 响应校验、融合张量形状和联合损失。
7. 实际数据清单与模拟传感器数据生成在本子目录内；原始目录 Git 状态不出现修改。

## 回合与角色

- 回合预算：2-4 轮，自动继续。
- 开发者：完成首个可运行版本和验证证据。
- 独立功能审查者：按需求符合度、正确性、完整性、可维护性和证据强度评分。
- 停止条件：总分不低于 4.3/5 且没有关键问题。
