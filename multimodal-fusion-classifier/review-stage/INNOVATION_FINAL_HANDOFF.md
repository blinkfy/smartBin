# 论文创新增强最终交付

## 核心创新

在原三模态分类器上增加跨模态一致性感知的传感器可靠性融合：

- 训练期软件模拟 missing、noise、spatial drift 和 stuck；
- 视觉多尺度特征与候选类别语义预测传感器潜表示及不确定性；
- 实际/预测潜表示的一致性、差异和不确定性共同产生逐样本可靠度；
- 可靠度控制实际传感器与预测潜表示的连续混合；
- 缺失传感器完全使用预测潜表示；
- CE + Focal 之外提供异方差潜表示重建和可靠度校准损失。

所有功能只依赖现有图像与 sidecar，不增加硬件、采集数据、在线 API 或第三方
依赖。当前模拟 sidecar 暂按观测传感器参与训练，日后保持 4×4 schema 即可
替换为真实记录。

## 论文实验支持

- 每一种软件退化都可独立关闭或设置强度。
- 两项辅助损失可分别关闭。
- FiLM 初值与不确定性范围可配置。
- epoch 历史分别记录分类、重建、校准、平均可靠度和一致性。
- CLI 支持显式 `--sensor-missing`。
- 新 checkpoint 支持正常、污染和缺失传感器；旧 checkpoint 仅支持有传感器
  的严格直通，不会静默使用未训练补全头。

## 验证

- 全量测试：72 passed。
- 数据校验：8,654 samples、8,654 sensors、0 errors、0 warnings。
- YOLO11s-seg 生产编码器：source indices `(16, 19, 22)`，三个输出均为
  `(1, 512)`。
- 独立审查：4.0 → 4.2 → 4.5，最终无 critical/important issue，STOP。

## 剩余边界

尚未执行完整 100 epoch 训练，也没有在真实物理传感器或外部数据集上报告
准确率。当前实现足以开展方法验证和消融实验，但论文中的最终性能结论必须
来自实际训练日志和严格划分的测试集。
