# 场景分析研究档案

本文按“通用中文计算机视觉/模式识别期刊预审要求”开展场景分析。当前未指定目标期刊，配置中也没有官方投稿网址或期刊样例，因此下述内容只给出跨期刊普遍适用的审稿要求和论文组织规律，不假定版式、篇幅、参考文献数量、基金标注方式或中英文摘要格式。待目标期刊确定后，仍需以其最新投稿须知逐项复核。

主线采用用户已确认的方案 A：**低质量图像条件软传感器下的可靠多模态垃圾分类**。场景判断以本地材料为准，尤其遵守 `EVALUATION_GOVERNANCE.md` 的测试集使用边界和 `PATENT_REQUIREMENT_MATRIX.json` 的专利对齐边界。

## 2. Review Criteria

### 2.1 审稿人问题清单

| 审稿问题 | 合格证据 | 当前判断与主要风险 |
|---|---|---|
| 研究问题是否比“提高垃圾分类准确率”更有价值？ | 真实说明软观测会缺失、受噪声、偏移或卡死，融合模型可能被低质量模态拖累 | 方案 A 的问题成立；必须把 clean 精度不是主要优势写清，否则容易被认为贡献与结果错位 |
| 软传感器是否提供独立于图像的新信息？ | 独立硬件测量、同步采集或明确的数据生成因果图 | 当前不具备。Qwen/rule-v1 都由图像条件生成，与视觉共享信息源；论文只能研究同源软观测的可靠使用和失效回退，不能证明物理多传感器互补 |
| 方法是否真正识别并抑制不可靠观测？ | 同一检查点开/关门控的前向干预、独立重训消融、可靠性随退化强度单调变化、错误案例分析 | 当前已有较强内部机制证据；正文应优先展示这些证据，而不是只给最终 Accuracy |
| 缺失模态恢复是否可信？ | 缺失时的潜表示预测、恢复误差、不确定性排序、任务性能和与简单替代策略的比较 | 可支持“潜空间误差排序改善”和“缺失回退”；异方差量值属于潜空间误差，不是物理传感器校准 |
| 模型是否只是复杂模块堆叠？ | 每个模块对应明确故障模式和可测中间量，消融能区分预测、质量、一致性、不确定性和门控的作用 | 需要用问题驱动图解释模块；Adapter、FiLM、注意力和余弦权重仅作为实现手段，不能逐一包装成独立创新 |
| 结果是否具有统计可信度？ | 源图聚类 bootstrap 区间、配对比较、少数类 support、去重敏感性、多种子结果和多重比较控制 | 已有内部统计治理基础；固定测试集多次访问使区间只能描述当前内部基准，不能恢复为确认性外部推断 |
| 数据划分是否泄漏？ | 按源图或采集序列分组、重复和近重复审计、训练/验证/测试职责固定 | 应明确源图分组和重复对象情况；原 826 条协议需完整保留，同时附报 825 条唯一对象敏感性结果 |
| 方法是否优于简单基线？ | 视觉单模态、视觉+文本、视觉+传感器、普通融合、完整门控及简单缺失填补基线 | 论文必须把基础融合基线与可靠融合分开；若 clean 指标相近，应以退化条件和机制证据解释价值，不得只强调最好点估计 |
| 退化是否贴近应用？ | missing、noise、bias/drift、stuck 的参数、强度、随机种子和组合规则公开，并讨论其与真实故障的差距 | 软件退化可用于受控压力测试，但未由硬件故障分布标定；“硬件鲁棒性”仍不可声称 |
| 是否具有外部泛化能力？ | 新采集批次、冻结模型与方案后解封标签、一次性主分析 | 当前没有外部盲测结果。任何“泛化到真实智能垃圾桶/新场景”的结论都应删除或改为待验证 |
| 是否达到完整专利复现？ | RGB-D、同步实体 4×4 阵列、医疗废物体系、专利步骤与性能逐项复核 | 未达到。矩阵中仅 6 项实现、9 项部分实现、3 项未实现，并存在任务范围调整和不可支持的性能主张 |
| 工程扩展是否抢占主线？ | 联合检测/分割与对象分类各自具有清晰接口、数据和指标，扩展不改变主问题 | YOLO11s-seg 联合头适合作为扩展或补充；不应把其 mAP 与对象级 Accuracy 合成一个“总体性能” |
| 论文是否诚实处理负结果？ | 报告 clean 无明显增益、Qwen/rule 来源差异、样本不足、校准局限和失败案例 | 这是本文可信度的重要组成部分；隐藏负结果反而会使审稿人怀疑选择性报告 |

### 2.2 建议的审稿优先级

对本文最关键的评审顺序应为：

1. **定义是否诚实**：软传感器是否被准确命名，19 类一般垃圾是否贯穿标题、数据和结论。
2. **机制是否成立**：门控能否在受控退化下识别低质量观测，并在缺失时稳定回退。
3. **对比是否公平**：完整方法、基线、消融和来源迁移是否属于同一实验谱系。
4. **统计是否克制**：固定测试集多次访问、重复对象、少数类和事后分析是否明确披露。
5. **外推是否受限**：是否避免把内部软件退化结果外推为硬件鲁棒性、外部泛化或专利性能复现。
6. **工程价值是否可解释**：方法是否为未来替换成同步硬件观测保留清晰接口，而非宣称替换已经完成。

其中第 1、3、4、5 项属于潜在预审拒稿点；模型结构再复杂也不能补偿定义和证据治理问题。

## 3. Accepted Paper Patterns

这里的“常见录用模式”是通用中文计算机视觉/模式识别论文的结构性规律，不代表对某一本期刊已录用论文的统计结论。当前 `source_index.md` 是本地材料索引，没有目标期刊官方样例或录用论文集，因此只能提炼跨场景可迁移的写法。

### 3.1 问题先于模型

较有说服力的论文先定义可观察的失败：低质量模态会使常规融合产生错误置信，缺失观测又会造成输入分布突变。随后每个方法部件分别回答一个问题：

| 失败问题 | 对应方法 | 审稿证据 |
|---|---|---|
| 传感器缺失后没有可用表示 | 视觉—文本条件潜表示预测 | missing 条件与简单填补基线、潜表示误差 |
| 原始 4×4 网格自身质量下降 | 网格质量编码与 availability | 质量分数随退化强度变化 |
| 软观测与视觉语义不一致 | 跨模态一致性估计 | 一致性与错误、门控值的关系 |
| 潜表示误差具有样本差异 | 异方差不确定性 | 方差—误差排序及温度校准边界 |
| 低质量观测仍可能污染融合 | 可靠性门控与连续回退 | 同检查点开/关门控和独立消融 |

这种“故障—机制—证据”链比按照网络前向顺序罗列 YOLO、CLIP、Adapter、FiLM 和注意力更容易通过创新性审查。

### 3.2 贡献与结果一一对应

常见的稳健组织方式是三项主贡献对应三组主证据：

1. **缺失回退机制**：证明没有 soft sidecar 时仍能形成连续、可运行的预测路径。
2. **可靠性门控机制**：证明门控不是装饰变量，而会因质量、一致性和不确定性发生可解释变化，并因果影响预测。
3. **分层评估协议**：在 clean、单一退化、混合退化、来源迁移和逐类条件下统一报告结果，同时保留无增益和失效条件。

专利式联合检测/分割头、Qwen 场景蒸馏和潜空间温度校准可作为扩展证据，不宜扩张为与主线并列的多个松散“创新点”。

### 3.3 实验由简单到困难

更符合审稿阅读习惯的结果顺序是：

1. 数据、划分、重复/近重复和软观测来源审计；
2. clean 条件下的视觉基线、普通融合和可靠融合；
3. 同检查点门控干预与独立重训消融；
4. missing、noise、bias/drift、stuck、mixed 的强度分层；
5. 不确定性、可靠性排序、校准和错误类型诊断；
6. Qwen/rule-v1 来源迁移及负结果；
7. YOLO11s-seg 联合头、分层目标和推理成本等扩展；
8. 外部盲测缺失、真实硬件缺失和专利差距。

该顺序让主张强度随着证据逐级增加，也避免用复杂扩展掩盖基础分类问题。

### 3.4 主指标、机制指标和扩展指标分层

成熟论文通常不把所有数字塞进一张总表。本文应形成三层：

- **任务层**：Accuracy、Macro Precision、Macro Recall、Macro F1、Weighted F1、逐类指标和源图聚类区间。
- **可靠性层**：NLL、Brier、ECE、可靠性分数、跨模态一致性、方差—误差 Spearman、退化强度响应。
- **系统扩展层**：box/mask mAP、召回率、参数量、推理时间和整图流程结果。

不同层只回答各自问题。例如 ECE 反映分类概率校准，不证明软传感器物理量被校准；box/mask mAP 反映联合头定位与分割，不替代对象级分类性能。

### 3.5 将负结果写成边界发现

在中文期刊稿中，负结果不应只埋在“局限性”末段。本文适合主动报告：

- clean 条件下 v3 相对 v2b 没有形成可观的广泛判别增益；
- 两模型多数共同错误具有相同错误类别，说明瓶颈不完全来自门控；
- Qwen/rule-v1 与视觉同源，不能验证独立物理模态互补；
- 潜方差的排序能力改善不等于绝对量值已具备物理校准意义；
- 小目标和高重叠代理样本量有限，不能形成稳健专门结论；
- 外部新批次与实体传感器实验仍缺失。

审稿价值在于把方法的有效条件和无效条件界定清楚，而不是把所有实验解释为正向提升。

### 3.6 以可复核图表替代宣传性表述

建议的核心图表模式为：

1. 一张问题驱动的总体架构图，标出 observed/predicted latent、availability、quality、consistency、uncertainty 和 gate。
2. 一张退化强度—任务指标—平均可靠性的联合曲线，观察门控响应是否与性能变化一致。
3. 一张同检查点门控干预或配对转移图，展示哪些样本由错转对、由对转错。
4. 一张逐类 support、F1 和区间图，防止少数类高点估计被误读。
5. 一张贡献—证据总表，明确哪些是主结果、事后诊断、扩展结果和未完成验证。

表题和图注应写明数据划分、样本单位、是否事后分析及是否为软件退化，避免读者脱离正文后误解。

### 4.2 论文的建议主张层级

**一级主张，可作为正文贡献：**

1. 面向图像条件软传感器退化，构建视觉—文本条件的潜表示预测与缺失回退路径。
2. 联合 availability、4×4 网格质量、跨模态一致性和潜空间不确定性估计传感器可靠性，并据此调节融合贡献。
3. 通过同检查点干预、独立重训消融和多类软件退化验证门控确实参与决策，而不是只依赖 clean 精度变化。

**二级主张，适合作为扩展或补充：**

1. 专利式 Adapter、FiLM、余弦权重、交互、残差和多尺度融合可接入原生 YOLO11s-seg Segment 头。
2. 潜空间温度缩放可改善内部基准上的绝对方差尺度，但不改变其物理意义边界。
3. Qwen/rule-v1 来源迁移、场景蒸馏及无明显增益结果用于说明同源软观测的能力上限。

**当前必须保留为局限：**

1. 没有同步 4×4 实体传感器、RGB-D 或真实故障标定。
2. 固定测试集已被反复用于内部研究判断，尚无新批次外部一次性盲测。
3. 当前类别体系为一般垃圾 19 类，不能外推到医疗废物。
4. 少数类别、极小目标和高重叠样本不足，逐类结论需同时报告 support 与区间。
5. Qwen服务输出依赖托管模型及其不可控修订，属性记录不是可溯源物理真值。

### 4.3 预审前的最低自检

在未指定具体期刊的情况下，建议把下列项目作为通用预审硬门：

- 标题、摘要、贡献和结论均以方案 A 为唯一主线，不出现“完整专利复现”“真实传感器”或“医疗废物系统已完成”。
- 每项主要贡献至少对应一项独立实验和一项机制证据，且所有数字可追溯到冻结报告或表格。
- 数据章节明确 19 类、源图分组、软观测来源、固定测试集访问、重复对象和去重敏感性。
- clean、退化、校准、逐类、消融和负结果完整报告，不以单一最好点估计代替整体证据。
- 对象分类与联合检测/分割分别定义样本单位、指标、模型和结论。
- 把事后分析明确标注为 exploratory/post hoc，把预注册实验与开发性实验分开。
- 局限性显式列出外部盲测、硬件、RGB-D、小目标/遮挡样本和 Qwen 可复现性缺口。
- 文献综述同时覆盖垃圾视觉、真实多传感器垃圾分拣、缺失/低质量模态、动态融合、不确定性与概率校准，并清楚说明本文与最接近方法的差异。
- 投稿前按最终目标期刊官方要求补齐具体版式与声明，不把本文件的通用要求误作某一期刊的正式格式。

综合判断：以方案 A 写成一篇**证据边界清楚的内部方法验证论文**是合理的；其可发表性主要来自可靠性机制与审计严谨性，而不是 clean 精度刷新或完整专利复现。缺少外部盲测不会阻止形成完整研究稿，但会限制泛化和部署主张，并可能成为强调工程落地或外部有效性的期刊审稿人要求补实验的首要问题。

换言之，当前研究稿必须把**外部盲测缺失**作为证据边界，而不能通过措辞将内部固定测试结果升级为外部确认。
