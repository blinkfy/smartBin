# 范文学习档案

## 使用范围与证据口径

- 研究场景：中文期刊论文，`tier=pro`。
- 控制动机：方案 A，即“低质量图像条件软传感器下的可靠多模态垃圾分类”。本文应把可靠性对象分类作为主线，把联合检测/分割、Qwen 蒸馏负结果、潜空间温度校准和专利对齐作为扩展证据。
- 本档案依据 `paper_spine_config.json`、本地 `source_index.md`、`LITERATURE_SCOUT.md`、`reference_candidates.bib`，并核对其中已有的 arXiv、CVF、PMLR 和 NeurIPS 官方摘要/元数据页面。
- 本阶段未通读候选论文 PDF 全文。“结构”均指标题、摘要、元数据和本地记录能够支持的**论证骨架**，不声称复原论文的逐节安排、公式细节或全部实验设置。
- SPIE 与 IEEE 的两项垃圾多传感器工作仅按本地记录和 BibTeX 元数据描述，不据此推断未见的性能结论。所有候选只用于学习组织和表达，不能替代本项目自己的实验数据与引用核验。

## 一、垃圾分类、检测与分割场景范文

### W1. WasteNet

**结构。** 可见论证骨架是“智能垃圾桶的本地决策需求 → 六类图像分类问题 → 轻量 CNN 与低功耗边缘设备 → 测试集准确率 → 对混投污染和云依赖的应用意义”。任务、设备和效益在摘要中构成单一闭环，没有把所有垃圾视觉问题混为一谈。

**论证。** 其说服力主要来自“为什么必须在边缘端做”与“模型是否达到该任务的分类效果”之间的直接对应。应用价值不是独立口号，而是由低功耗部署和实时决策条件承接。

**可借鉴点。** 本文引言可先写垃圾投放端观测可能不完整，再把研究问题收束为对象级可靠分类；系统章节随后说明模型如何在软传感器缺失时连续回退。实验中应将 Accuracy、Macro F1、参数量和推理时间分别对应分类有效性、长尾公平性与部署成本。

**不可照搬边界。** WasteNet 是六类单图分类和边缘部署范例，不能据其任务设置替代本项目 19 类定义，也不能把本项目尚未完成的真实智能桶端测试写成已部署。其准确率不可与当前不同数据划分的结果横向排名。

### W2. TACO

**结构。** 官方摘要清楚采用“野外垃圾检测需求 → 开放数据集及配套工具 → Mask R-CNN 实例分割基线 → 数据规模不足 → 继续众包标注”的结构。数据贡献、基线验证和未解决问题同时出现。

**论证。** 它没有用一次基线结果掩盖数据不足，而是把有限规模明确写成达到实际部署效果的障碍。由此形成“资源可用，但结论仍有限”的可信叙事。

**可借鉴点。** 本文的数据章节应同样把 8654 条对象记录、5990 张源图、Qwen 覆盖与 rule 回退写成可审计流程；结果章节在报告固定内部测试集指标后，应立即说明该测试集已被多轮分析使用，外部盲测尚待完成。

**不可照搬边界。** TACO 的核心是野外检测与 polygon 标注，本项目主结果是已有框裁剪条件下的对象分类。不能用 TACO 的“in-the-wild”表述包装当前受控对象分类，也不能把对象 Accuracy 与实例分割 AP 放在同一比较列。

### W3. ZeroWaste

**结构。** 可见骨架是“回收效率问题 → 工业垃圾流的极端拥挤、可变形和透明目标 → 现有数据缺口 → 工业级检测/分割数据集 → 促进极端拥挤视觉研究”。场景属性本身定义了研究挑战。

**论证。** 该工作不是先给数据集名称再寻找意义，而是先证明普通对象中心数据不能代表工业传送带垃圾流，然后让真实场景采集成为对缺口的直接响应。

**可借鉴点。** 本文可用同样的“失效条件先行”方式：先展示软传感器的 missing、noise、bias/drift、stuck 退化会破坏直接融合，再引出网格质量、跨模态一致性、不确定性门控和预测潜表示回退。联合 YOLO11s-seg 结果可作为从对象分类走向复杂场景的扩展，而非挤占主线。

**不可照搬边界。** 当前数据缺少 ZeroWaste 所代表的工业拥挤度、真实传送带域和充分小目标样本。现有联合检测/分割高 mAP 不能被描述为在 ZeroWaste 式极端拥挤场景中得到验证。

### W4. Multi-Sensor Data Fusion Using Deep Learning for Bulky Waste Image Classification

**结构。** 本地记录和元数据支持的骨架是“体积垃圾识别需求 → RGB、近红外高光谱、热成像、太赫兹等独立传感器 → 早期/中期/晚期融合比较 → 分类任务验证”。其组织单位是融合层级，而不是模块名称堆叠。

**论证。** 多模态价值由不同物理传感器提供的互补信息支撑；早、中、晚融合形成可比较的设计轴，使“融合有效”成为可检验命题。

**可借鉴点。** 本文消融表可沿用“信息源与融合位置”的二维组织：视觉单模态、视觉+文本、视觉+软传感器、普通直接融合、完整可靠性融合；再把是否启用退化训练、潜表示重建和校准损失作为机制消融，避免按代码类名零散排列。

**不可照搬边界。** 本项目的 Qwen/rule-v1 观测由图像条件生成，与 RGB 共享信息源，不是近红外、高光谱、热成像或太赫兹测量。只能借鉴融合比较结构，不能继承“独立物理模态互补”的因果解释；本阶段也未读取该论文全文，不能转述具体网络和性能。

### W5. SpectralWaste

**结构。** 本地记录和 IEEE 元数据支持的骨架是“真实分拣自动化需求 → 分拣设施中的同步 RGB-高光谱数据 → 多模态分割任务 → 面向工业场景的基准价值”。数据同步和真实设施是其证据链关键。

**论证。** 其多模态主张建立在同一现场、同步采集的物理观测上，因此数据来源本身就是方法有效性解释的一部分，而不只是附录细节。

**可借鉴点。** 本文应在方法前单设“观测来源与依赖关系”，明确图像、CLIP 类别文本和图像条件软传感器并非三个独立物理通道。讨论部分可将真实同步传感器替换接口列为确认性扩展，形成“当前验证了什么、下一步怎样升级证据”的路线。

**不可照搬边界。** 不得用“同步采集”“高光谱”或“真实传感器融合”描述当前 sidecar；当前 4×4 网格也不能与高光谱像素或材料光谱等同。本阶段未读取该论文全文，不推断其具体融合网络、效率或性能优势。

### W6. SortWaste

**结构。** 官方摘要呈现“真实垃圾流的变异与拥挤 → 缺少工业检测数据 → 密集标注数据集 → 以对象数、类别/尺寸熵和重叠构造 ClutterScore → 按困难度报告检测基线 → 高拥挤下性能下降”的完整链条。

**论证。** 亮点不是只给总体 mAP，而是先定义可解释的场景难度，再证明总体平均值会遮蔽高拥挤条件下的失败。指标下降反过来验证了困难度划分的研究价值。

**可借鉴点。** 本文应保留已经建立的目标尺寸与重叠分层，并在扩展结果中将 small/medium/large、isolated/low/high 与 box/mask mAP 对应。对象分类主结果也应报告类别区间和源图聚类置信区间，避免只展示单一总体准确率。

**不可照搬边界。** 当前 small 与 high-overlap 样本量不足，分层结果只能作为描述性或探索性证据，不能作强泛化结论。也不应直接复用 ClutterScore 名称或公式，除非阅读全文、正式引用并在本项目数据上严格实现。

### W7. ScatSpotter

**结构。** 官方摘要的骨架是“小型、无定形、易伪装废弃物的识别需求 → 手机图像和 polygon 标注 → 同地点 before/after/negative 采集协议 → 检测/分割研究 → 基础模型覆盖不足”。采集设计主动控制了背景和混淆物。

**论证。** BAN 协议把正样本、移除目标后的同视角背景和附近相似负样本联系起来，使“模型识别目标而非记住场景”更可检验；负结果也用于界定通用模型的能力边界。

**可借鉴点。** 外部盲测可学习这种协议思维：按采集批次、会话和设备记录来源，设置独立负样本，标签解封晚于协议冻结，并排查与开发集的精确及近重复图像。Qwen 蒸馏未带来显著分类增益的结果也应保留，用于排除“增加软观测必然提升精度”的叙事。

**不可照搬边界。** 当前数据没有 BAN 配对采集，不能声称已控制场景记忆；小目标只有 11 个标准化实例，不能据此宣称解决小型伪装垃圾。ScatSpotter 的具体基础模型结果不应迁移为本项目结论。

## 二、低质量、缺失模态与不确定性 SOTA 范文

### R1. Are Multimodal Transformers Robust to Missing Modality?

**结构。** 可见骨架是“现实数据常有模态缺失 → 提出融合模型是否天然鲁棒的问题 → 系统比较缺失条件和融合策略 → 发现敏感性及数据集依赖性 → 自动搜索输入相关融合策略 → 多基准验证”。诊断实验先于方案。

**论证。** 论文先推翻“强融合模型自然能处理缺失”的隐含假设，再把方法设计建立在两个经验发现上：缺失会显著降级，且不存在普适固定融合策略。方法不是凭空增加模块。

**可借鉴点。** 本文结果顺序应为：完整观测基线；同检查点的软件退化曲线；普通直接融合在缺失下的失败；可靠性门控和潜表示回退；关闭门控与打乱软观测的机制验证。这样“为何需要门控”先由数据回答。

**不可照搬边界。** 该工作研究 Transformer 和多个图文基准，本项目使用 YOLO 多尺度视觉特征、CLIP 类别原型与网格软观测。不能把“自动搜索融合策略”写成当前固定结构的功能，也不能声称跨数据集普适鲁棒。

### R2. Provable Dynamic Fusion for Low-Quality Multimodal Data

**结构。** 官方摘要的骨架是“跨模态相关与交互困难 → 低质量数据需要动态融合 → 现有动态融合缺少理论解释 → 从泛化角度给出理论理解 → 不确定性可用于鲁棒融合 → 提出质量感知多模态融合 QMF → 多基准验证”。

**论证。** 其核心推进是把“动态加权有效”的经验命题提升为“为何质量/不确定性能够控制融合”的理论问题。标题、问题、方法和验证围绕 quality-aware 这一概念保持一致。

**可借鉴点。** 方案 A 可借鉴这种单概念统领：把网格质量、跨模态一致性和潜空间不确定性统一解释为软传感器可靠性证据，最终共同决定门控权重；每个辅助损失都必须回到“可靠性是否可排序、缺失时是否回退”这一主张。

**不可照搬边界。** 本项目没有复现或扩展 QMF 的理论证明，不能使用“可证明鲁棒”措辞。当前证据是固定内部测试集上的软件退化、门控排序和五种子结果，只支持经验性、条件化结论；方法差异必须在相关工作中明确。

### R3. Distribution-Consistent Modal Recovering

**结构。** 可见骨架是“恢复缺失模态有助于下游任务 → 直接点估计忽视跨模态分布差异 → 定义分布不一致问题 → 通过类别条件 normalizing flow 转移分布 → 恢复后与可用模态联合分类 → 多种缺失模式与分布可视化验证”。

**论证。** 方法动机由对既有恢复范式的具体缺陷推出：不是笼统说恢复不准，而是指出恢复数据与真实缺失模态之间存在分布差距，并为此选择可逆密度建模。

**可借鉴点。** 本文描述“视觉-文本预测传感器潜表示”时，应先定义它解决的是缺失时的连续回退，而不是声称重建真实物理信号。讨论中应主动比较点预测加异方差 NLL 与完整分布恢复的区别，并将潜空间温度校准作为尺度修正证据。

**不可照搬边界。** 当前模型没有 normalizing flow、类别条件密度转移或真实缺失模态分布监督，不能声称分布一致恢复。Qwen/rule sidecar 又与图像条件相关，因此其恢复误差不能外推为硬件传感器恢复能力。

### R4. Embracing Unimodal Aleatoric Uncertainty

**结构。** 官方摘要的骨架是“单模态嵌入含潜在噪声 → 噪声破坏跨模态交互 → 将偶然不确定性量化并用于稳定表示学习 → SUFA 结合不确定性与自监督对比学习 → RMFI 学习紧凑联合表示 → 多种模态和多数据集验证抗噪性”。

**论证。** 不确定性不是结果表之后的附加可视化，而是同时进入单模态表示稳定化和跨模态融合。两个模块分别对应“先稳定每个模态”和“再稳健整合”的因果链。

**可借鉴点。** 本文方法图和方法章节应明确三个层次：潜表示及 log-variance 估计；一致性和质量联合门控；门控后的 Adapter/FiLM/注意力融合。结果必须分别验证潜变量尺度、可靠性排序和最终分类，而非仅凭总准确率证明全部机制。

**不可照搬边界。** 本项目的 log-variance 表示传感器潜空间重建误差，不等于物理测量噪声，也未采用 EAU 的 SUFA/RMFI。温度校准改善的是潜空间误差尺度，不应写成真实传感器概率校准或跨域不确定性保证。

### R5. Probabilistic Conformal Distillation

**结构。** 官方摘要采用“完整模态训练、缺失模态测试导致降级 → 点对点跨模态蒸馏因不可修复的信息不对称而过严 → 将映射变量建模为概率分布 → 约束概率极值与不同分布峰值的几何一致性 → 多基准验证”的结构。

**论证。** 关键修辞是把“点对点对齐”从常规做法转化为待质疑假设，并用信息不对称解释其为何会捕获伪因素。概率建模直接回应了这个缺陷。

**可借鉴点。** 本文应把 Qwen 场景蒸馏的无显著增益写成有解释力的负结果：图像条件教师聚合为场景网格后，学生虽能逼近空间模式，但同源信息和点估计限制使其未形成稳定分类增益。这可自然引出更严格概率映射作为未来工作。

**不可照搬边界。** 当前 Qwen 蒸馏不是 PCD，没有共形约束、概率密度学习或覆盖保证；不能借“probabilistic”一词抬高异方差 NLL。现有蒸馏结果只能支持“该实现未显示显著增益”，不能证明所有软传感器蒸馏无效。

### R6. Hyper-Modality Enhancement

**结构。** 官方摘要的骨架是“现实中的缺失来自损坏、故障或隐私 → 显式模态重建依赖完整训练样本 → 从其他样本检索语义线索以增强观测模态 → 以不确定性感知融合平衡原始和增强表示 → 多种缺失条件验证”。它提供了“不显式重建”的替代路线。

**论证。** HME 同时回答两个问题：缺什么信息，以及新增线索是否可信。跨样本增强负责补充，不确定性机制负责控制增强表示的影响，避免把补全和融合混成一个黑箱。

**可借鉴点。** 本文可用“预测表示不等于伪造观测”的表述：缺失时保留视觉-文本预测潜表示作为回退候选，再由可靠性门控决定其贡献。相关工作应把显式观测重建、潜表示回退和跨样本增强分成三类路线。

**不可照搬边界。** HME 面向多模态情感分析并使用跨样本检索，本项目没有 hyper-modality 或检索增强。不得把当前 CLIP 类别描述称为从其他样本恢复的模态，也不能由情感基准结果推断垃圾分类鲁棒性。

## Structural Patterns

### 1. 推荐的全文主骨架

1. **场景约束先行。** 从智能垃圾分类中的低质量或缺失辅助观测切入，不以“多模态通常更好”作为起点。
2. **失败模式具体化。** 定义 missing、noise、bias/drift、stuck，并解释普通直接融合为何可能放大错误信息。
3. **证据驱动的方法展开。** 按“观测编码 → 预测潜表示 → 不确定性 → 质量/一致性门控 → 调制与注意力融合”展开；每个模块对应一个已定义的失败模式。
4. **先诊断，后比较。** 结果先展示完整观测与退化下的基线行为，再报告完整方法；避免第一张表直接堆模型排名。
5. **贡献逐项验证。** 主结果验证对象级分类；同检查点干预验证门控；连续退化验证可靠性排序；温度校准验证潜空间尺度；联合检测/分割验证系统扩展。
6. **负结果和边界收束。** Qwen 蒸馏无显著分类增益、small/high-overlap 样本不足、固定内部测试集被多轮使用、缺少硬件与外部盲测，均在讨论中明确保留。

### 2. 推荐的结果章节顺序

1. 数据、划分、观测来源和评估治理。
2. 主要对象分类结果：Accuracy、Macro F1、Weighted F1、类别指标与源图聚类区间。
3. 低质量和缺失条件：统一退化强度下的性能曲线及 clean-to-degraded 降幅。
4. 可靠性机制：门控关闭、软观测打乱、缺失回退、可靠性排序和五种子稳定性。
5. 消融：模态组合、普通融合与可靠融合、退化训练、重建损失、校准损失。
6. 潜空间不确定性：原始尺度、验证集拟合温度、一次性测试结果；与分类 ECE 分开。
7. 扩展：联合检测/分割、尺寸/重叠分层、Qwen 蒸馏负结果和专利功能对齐。
8. 限制与外部验证协议。

### 3. 表图的职责分工

- **主表**回答方案 A 是否在对象分类和退化条件下成立，不混入 box/mask mAP。
- **退化曲线**回答鲁棒性随强度如何变化，不能只列一个 100% missing 点。
- **门控/一致性图**回答机制是否按质量变化，而不是再次展示准确率。
- **混淆矩阵与类别区间**回答总体 Macro F1 的来源及长尾风险。
- **检测/分割表**单独报告 box 与 mask mAP，并标明它是扩展系统任务。
- **负结果表**保留 Qwen 场景蒸馏 matched/fallback/shuffled 的近零差异，防止选择性报告。

## Rhetorical Patterns

### 1. 用“条件化主张”替代“全面领先”

应写：“在固定内部划分和预定义软件退化条件下，可靠性门控表现出一致的质量排序与缺失回退行为。”不应写：“所提方法在真实复杂环境中具有普适鲁棒性。”

### 2. 由失败证据推出模块

每个模块前使用“观测到的问题 → 需要的性质 → 设计选择”三步。示例：“直接融合无法区分卡死网格与稳定观测，因此融合权重必须同时依赖局部质量与跨模态一致性；据此构造可靠性门控。”避免“为了进一步提升性能，我们增加……”。

### 3. 把无增益结果写成边界证据

Qwen 蒸馏段落应先陈述实验问题，再给出同检查点 matched/fallback/shuffled 比较，最后解释它限制了“软观测增加即带来互补增益”的说法。不要把无增益隐藏到补充材料一句带过，也不要反向夸成有效提升。

### 4. 区分三类不确定性/校准

- 分类置信度及 ECE：回答预测概率与分类正确性的对应关系。
- 潜空间 log-variance：回答预测传感器表示的条件误差尺度。
- 物理传感器测量不确定性：当前没有硬件证据，不能宣称已校准。

三者必须分段命名，不使用一个“校准良好”概括。

### 5. 让限制与结论使用同一名词体系

若方法部分称“图像条件软传感器”，结论和限制也保持这一称谓；不得在结果中悄然改称“传感器实测数据”。若主任务称“对象级分类”，摘要中也不以“垃圾检测系统”替换，联合检测/分割只作为扩展。

### 6. 对比较公平性作前置说明

在表格前说明同划分、同检查点、同退化协议和选择规则；对于不同数据集的外部论文，只做任务与方法定位，不做数值排名。固定内部测试集已被反复分析，应称“内部确认性基准”，外部盲测保持待完成状态。

## Language Patterns

### 1. 推荐句式

- **界定问题：**“本文关注的不是完整观测下的静态融合，而是辅助软观测发生缺失、噪声、偏移或卡死时的可靠性控制。”
- **说明来源：**“4×4 sidecar 由目标图像条件下的视觉语言模型或确定性规则生成，属于软传感器先验，不构成独立硬件测量。”
- **引出方法：**“为避免低质量观测在融合阶段被等权放大，本文联合估计网格质量、跨模态一致性与潜表示不确定性。”
- **表达回退：**“当观测不可用时，模型连续降低观测分支权重，并保留视觉-文本预测潜表示作为回退候选。”
- **报告结果：**“在预定义退化协议下，完整方法相对普通融合表现出更稳定的性能变化；该结论限于当前内部划分。”
- **陈述无增益：**“场景级 Qwen 蒸馏未产生可辨别的分类增益，因此该扩展被保留为负结果，而不作为主要贡献。”
- **表述限制：**“由于软观测与图像共享信息来源，现有实验不能证明独立物理模态的互补收益。”

### 2. 应避免的句式

- “首次实现了真实多传感器垃圾分类系统。”
- “显著优于现有所有方法。”除非存在同数据、同协议、统计检验和完整基线。
- “不确定性得到准确校准。”应指明是分类概率还是潜空间误差，并给出限定范围。
- “模型可适应任意传感器故障。”当前只覆盖预定义软件退化。
- “检测精度达到……”后接对象级 Accuracy；检测、分割与分类指标不可混称。
- “Qwen 提供真实重量、温度、湿度等传感器值。”应改为图像条件属性估计或软观测。
- “外部测试证明……”当前外部盲测只有冻结协议与接入工具，尚无新批次数据。

### 3. 术语一致性表

| 容易混淆的写法 | 统一写法 | 原因 |
|---|---|---|
| 真实传感器数据、物理测量 | 图像条件软传感器观测 / sidecar | 数据由图像统计或 Qwen 视觉推断生成 |
| 传感器重建 | 传感器潜表示预测/回退 | 当前不恢复可验证的物理读数 |
| 多模态精度 | 对象分类 Accuracy/Macro F1，或 box/mask mAP | 任务和指标必须配对 |
| 最终盲测集 | 固定内部测试集 | 该划分已被多轮分析 |
| 证明鲁棒 | 在预定义退化条件下支持鲁棒性 | 当前没有理论证明与外部域验证 |
| 不确定性校准 | 潜空间温度缩放 / 分类概率 ECE | 两种校准对象不同 |
| 专利复现完成 | 专利功能栈的软件对齐/近似实现 | 尚缺 RGB-D、实体阵列和医疗废物体系 |

## 对方案 A 的直接写作约束

1. 标题、摘要、引言末段和结论必须共同围绕“低质量图像条件软传感器下的可靠融合”，不能以最高分类精度或完整专利复现作为中心。
2. 三项主要贡献宜分别落在：退化感知可靠性门控；缺失时的潜表示连续回退；同检查点干预、连续退化和多种子组成的机制证据。联合分割属于系统扩展。
3. 相关工作宜分为“垃圾视觉任务”“真实垃圾多传感器”“低质量/缺失模态融合”“不确定性与校准”四组，并在每组末尾写与本项目的可验证差异。
4. 结果段落采用“研究问题 → 对照 → 观察 → 对贡献的支持 → 边界”五句式，避免表后只复述最大值。
5. 任何来源于外部范文的性能数字只能用于介绍该文自身，不能作为本项目的基线；正式稿引用前仍需逐项核对 BibTeX、原文上下文和目标期刊格式。
