# 中文期刊论文写作风格

## 总体结构

采用“问题定义—方法承诺—验证证据—适用边界”的 IMRaD 主线。引言只提出一个
控制性问题：图像条件软传感器质量变化时如何进行可靠融合。对象级 v3 是主模型，
联合检测分割、Qwen 蒸馏和专利对齐是扩展，不与主贡献争夺标题位置。

## 章节节奏

1. 摘要按背景一句、方法两句、实验两句、边界一句组织，不堆模块名。
2. 引言先从垃圾视觉和真实物理多传感器的差距切入，再落到低质量/缺失模态，
   最后给出三项可验证贡献。
3. 相关工作分为垃圾视觉与物理多传感器、缺失/低质量模态、方法基础三组。
4. 方法按数据流顺序写：编码、潜表示与不确定性、质量门控、融合、联合目标。
5. 结果章节每节先写验证问题，再写比较和区间，最后写一句边界。
6. 限制章节必须保留软观测同源性、固定内部测试复用、外部盲测缺失、类别不平衡、
   小目标/高重叠样本不足和硬件/RGB-D 缺失。

## 语言规则

- 使用“本文”“该模型”“该条件”，避免“革命性”“显著领先”等营销词。
- “显著”只在有预先定义的统计证据时使用；其余写“点估计提高”“区间跨 0”
  或“三个训练种子方向一致”。
- 百分比统一保留两位小数；差异写百分点（pp），不混写相对百分比。
- Accuracy、Macro F1、ECE、NLL、Brier 和 mAP 首次出现时给出中文含义。
- 对象级分类和 box/mask mAP 始终分段、分表报告。
- 所有 Qwen/rule-v1 数据写为“图像条件软传感器观测”或“sidecar”。
- 不使用第一人称复数口语，不写训练过程流水账；完整性事件压缩进可复现性小节。

## 引用规则

- 方法基础引用原始论文；垃圾场景与低质量模态优先引用官方会议页面或 DOI。
- YOLO11 只能引用官方实现文档，不把文档包装成同行评议方法论文。
- Qwen3-VL 技术报告只支撑模型族背景，不证明托管 `qwen3-vl-flash` 修订版可逐位
  复现。
- 每个文献引用必须承担明确命题，不用连续堆砌引用替代分析。

## 表图规则

- 表格标题说明数据划分、训练种子数、差值方向和区间单位。
- 置信区间写明以 `source_image_id` 为簇的 bootstrap。
- 架构图突出 availability、预测潜表示、观测到预测的连续插值和可靠性门控。
- 联合头图明确 RGB 主干保持三通道，外部网格不冒充深度。
- 图注内包含“内部固定测试”或“开发扩展”标签，避免脱离正文后被误读。

## 证据与论断纪律

- 摘要、结果与结论中的核心数值必须能回指冻结 JSON 产物；不从终端截图或最后一轮
  日志人工抄录替代正式评估。
- 三训练种子均值使用“均值 ± 样本标准差”，单检查点扰动重复不得包装成独立训练
  重复；同检查点门控开关只能支持行为干预解释，不能替代重新训练消融。
- 区间跨零时保留方向与效应量，但不使用“证明有效”或“统计显著”；仅当预定义检验
  与区间共同支持时，才陈述较强结论。
- 潜空间方差、标准化残差与 Spearman 相关性只说明不确定性排序或校准状态，不写成
  温度、湿度、重量等物理量误差，也不把 512 维聚合结果解释为独立测量。
- 负结果保留在结果与讨论中，并说明它限制了哪一项主张；历史路线探索不得选择性
  删除，也不得与冻结主实验混成同一证据层级。
- 对重复裁剪、近重复候选、固定测试集复用和检查点恢复等完整性事件，正文只保留会
  改变结论边界的信息，详细哈希和恢复记录留在可复现性归档中。

## 术语与边界

- “软传感器”专指由目标图像条件估计的结构化 sidecar 接口；“传感器观测”在首次
  出现时必须带来源限定，避免读者误解为同步硬件阵列。
- “可靠性”表示当前接口在已定义缺失与软件退化下的相对可用性，不等同于安全认证、
  物理计量可信度或真实故障概率。
- “内部固定测试”与“外部盲测”严格区分；只要测试集参与过路线判断，就不得写成
  从未访问的最终留出集。
- 19 类标签按现有对象本体报告，不上升为法律垃圾大类、医疗废物体系或通用开放集
  分类标准。
- `clean` 表示未注入注册软件退化，不表示 sidecar 无估计误差；`missing`、`noise`、
  `bias`、`stuck` 和 `mixed` 始终保留英文场景名以便与代码、表格和归档一致。

## 版式与可读性

- 正文采用 A4 单栏中文期刊预稿式排版，中文宋体、标题黑体、英文与数字 Times New
  Roman；标题、超链接和交叉引用均以黑色输出。
- 一级至三级标题层级稳定，不使用彩色装饰；正文两端对齐，公式居中，图表不跨越
  页边距，表头在必要时重复。
- 图、表按正文首次出现顺序连续编号，题注应能脱离正文独立理解来源、样本单位、
  统计方向与限制。
- 参考文献采用数字顺序制；网页与技术文档保留可核验链接，但不让长 URL 挤压正文
  栏宽或产生不可读的孤行。
- 每轮最终导出后检查全部页面缩略总览，并对标题页、跨页表格、公式页、四幅图和
  参考文献末页进行单页复核；无裁切、重叠、未解析标签或异常空白方可交付。
