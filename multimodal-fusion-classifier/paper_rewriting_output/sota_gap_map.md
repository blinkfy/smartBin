# SOTA 与研究空缺映射

## 定位与材料边界

本文采用方案 A“低质量图像条件软传感器下的可靠多模态垃圾分类”。控制性问题是：当图像条件软传感器发生缺失、噪声、偏移或卡死时，如何在保留视觉、类别文本与软观测互补性的同时，抑制不可靠信息，并在观测缺失时连续回退到预测潜表示。

本映射仅依据 `LITERATURE_SCOUT.md` 所列候选文献以及项目内绑定证据，属于论文写作前的 SOTA 预映射，不等同于系统综述。Qwen 与 rule-v1 数据统一视为图像条件软传感器、sidecar 或视觉语义辅助先验；固定内部测试集不视为外部盲测；对象级 Accuracy/Macro F1 与联合检测分割的 box/mask mAP 不作横向合并。

## Gap Summary

1. **主贡献应落在“可靠性机制及其证据闭环”，而非“首次多模态融合”或“刷新垃圾分类精度”。** 最可辩护的空缺是：在一般垃圾对象分类的图像条件软传感器场景中，将视觉—文本潜表示回退、网格质量、跨模态一致性、可用性与不确定性组织为可靠融合机制，并以三种子独立消融、注册软件退化和同检查点干预证明机制参与。
2. **SOTA 已覆盖缺失模态恢复、低质量动态融合和不确定性感知。** 因而本文的算法新颖性必须限定为特定问题设定、门控信号组合与验证设计；不能把通用模态恢复、动态融合、FiLM、注意力或温度缩放单独包装成首创。
3. **联合 Segment 头是支持性系统扩展。** 当前证据足以说明多模态条件进入 P3/P4/P5 并影响原生头前特征，但不足以证明 sidecar 带来检测分割优势。其最合适角色是展示方案 A 从对象分类向检测分割的结构可迁移性，并公开与专利的实现边界。
4. **不确定性温度校准是解释性补充。** 它改善潜空间概率量值，但不构成物理传感器校准；应与分类 ECE、硬件校准和外部泛化严格分开。
5. **负结果必须保留。** Qwen 蒸馏 sidecar 可重建但未改善下游任务，来源比较多数区间不确定，小目标和高重叠代理样本受限。这些结果反而支撑论文把贡献聚焦到退化条件下的可靠机制，而不是模态增益或极端场景性能。
6. **投稿级剩余证据空缺不应被措辞掩盖。** 新采集外部盲测、正式整图 Qwen 三种子实验、同步实体阵列、RGB-D 与人工遮挡标注仍未完成。当前稿件可形成方案 A 的内部证据论文，但不得升级为硬件验证、完整专利复现或外部部署结论。

建议采用的中心定位句为：**本文研究的不是独立物理传感器带来的额外信息增益，而是图像条件软传感器在缺失和低质量条件下如何被可靠使用、抑制并连续回退；贡献由机制干预和注册退化证据支撑，联合检测分割与不确定性校准作为边界清晰的支持性扩展。**
